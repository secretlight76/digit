Introduction à la Numérisation Audio

Qu'est-ce que la numérisation audio ?

La numérisation audio est le processus de conversion d'un signal audio analogique (continu) en un signal numérique (discret) que les ordinateurs peuvent traiter et stocker.

Les trois étapes fondamentales :

  1. Échantillonnage (Sampling) : Mesurer l'amplitude du signal à intervalles réguliers
  2. Quantification : Convertir chaque mesure en valeur numérique
  3. Encodage : Stocker les valeurs en format binaire

Échantillonnage (Sample Rate)

Qu'est-ce que l'échantillonnage ?

L'échantillonnage consiste à mesurer l'amplitude d'un signal audio à intervalles réguliers. La fréquence d'échantillonnage (ou sample rate) détermine combien de fois par seconde le signal est mesuré.

Fréquences d'échantillonnage courantes :

  • 8 kHz : Téléphonie
  • 22.05 kHz : Radio AM
  • 44.1 kHz : CD Audio (standard)
  • 48 kHz : Production vidéo professionnelle
  • 96 kHz / 192 kHz : Audio haute résolution

📚 Théorème de Shannon-Nyquist

Pour reproduire correctement un signal, la fréquence d'échantillonnage doit être au moins deux fois supérieure à la fréquence maximale du signal.

féchantillonnage ≥ 2 × fmax

Exemple : L'oreille humaine perçoit jusqu'à ~20 kHz, donc 44.1 kHz est suffisant (2 × 20 kHz = 40 kHz).

Quantification (Bit Depth / Résolution)

Qu'est-ce que la quantification ?

La quantification convertit chaque échantillon mesuré en une valeur numérique. La résolution (bit depth) détermine la précision de cette conversion.

Résolutions courantes :

  • 8 bits : 256 niveaux (28) - Qualité téléphone
  • 16 bits : 65 536 niveaux (216) - CD Audio
  • 24 bits : 16 777 216 niveaux (224) - Production professionnelle
  • 32 bits float : Très haute précision - DAW modernes

📚 Rapport Signal/Bruit (SNR)

Plus la résolution est élevée, plus le rapport signal/bruit est bon :

SNR (dB) ≈ 6.02 × bits + 1.76

  • 16 bits : ~96 dB SNR
  • 24 bits : ~144 dB SNR

Le bruit de quantification diminue avec l'augmentation du nombre de bits.

Aliasing et Repliement Spectral

Qu'est-ce que l'aliasing ?

L'aliasing (ou repliement spectral) se produit lorsqu'un signal contient des fréquences supérieures à la moitié de la fréquence d'échantillonnage (fréquence de Nyquist).

⚠️ Le problème de l'aliasing

Lorsque le théorème de Shannon-Nyquist n'est pas respecté, les hautes fréquences sont mal interprétées et apparaissent comme des basses fréquences parasites.

fNyquist = féchantillonnage / 2

📚 Filtres Anti-Aliasing

Pour éviter l'aliasing, on utilise un filtre passe-bas avant l'échantillonnage :

  • Élimine les fréquences au-dessus de la fréquence de Nyquist
  • Appliqué lors de la conversion analogique-numérique (ADC)
  • Essentiel pour une numérisation de qualité

Débit (Bitrate)

Qu'est-ce que le débit ?

Le débit (bitrate) représente la quantité de données audio par seconde, mesurée en kilobits par seconde (kbps) ou mégabits par seconde (Mbps).

Calcul du débit pour l'audio non compressé :

Débit = Fréquence d'échantillonnage × Résolution × Nombre de canaux

Exemple CD Audio : 44 100 Hz × 16 bits × 2 canaux = 1 411 200 bits/s = 1 411 kbps ≈ 1.4 Mbps

📚 Types de débit

  • CBR (Constant Bitrate) : Débit constant tout au long du fichier
  • VBR (Variable Bitrate) : Débit variable selon la complexité du signal
  • ABR (Average Bitrate) : Débit moyen ciblé avec variations

Canaux Audio

Qu'est-ce qu'un canal audio ?

Un canal audio représente un flux audio indépendant. Le nombre de canaux détermine la spatialisation et l'immersion sonore.

Configurations courantes :

  • Mono (1.0) : 1 canal - Téléphonie, radio AM
  • Stéréo (2.0) : 2 canaux (G/D) - CD, streaming, production standard
  • 2.1 : Stéréo + subwoofer
  • 5.1 : Avant G/D, Centre, Arrière G/D, Subwoofer - Cinéma, DVD
  • 7.1 : 5.1 + Latéral G/D - Cinéma haute-gamme
  • Dolby Atmos : Canaux orientés objets 3D

📚 Techniques de spatialisation

  • Pan (Panoramique) : Répartition G/D en stéréo
  • IID (Interaural Intensity Difference) : Différence de niveau entre les oreilles
  • ITD (Interaural Time Difference) : Différence de temps d'arrivée
  • HRTF (Head-Related Transfer Function) : Simulation 3D avec 2 canaux

Compression Audio

Qu'est-ce que la compression audio ?

La compression audio réduit la taille des fichiers audio en éliminant les informations redondantes ou inaudibles.

Deux types de compression :

  • Sans perte (Lossless) : Compression réversible, qualité identique à l'original
    • FLAC (Free Lossless Audio Codec) - Open source
    • ALAC (Apple Lossless) - Apple
    • WAV / AIFF - Non compressés
  • Avec perte (Lossy) : Compression irréversible, perte de qualité acceptable
    • MP3 (MPEG-1 Audio Layer 3) - Standard universel
    • AAC (Advanced Audio Coding) - Meilleur que MP3, iTunes/YouTube
    • Opus - Open source, très efficace, WebRTC
    • OGG Vorbis - Open source
    • WMA (Windows Media Audio) - Microsoft

📚 Modèle psychoacoustique

Les codecs avec perte utilisent le masquage psychoacoustique :

  • Masquage fréquentiel : Sons forts masquent les sons faibles proches en fréquence
  • Masquage temporel : Sons forts masquent brièvement avant/après leur occurrence
  • Seuil d'audition : Fréquences inaudibles sont éliminées

Ces techniques permettent une réduction de 75-90% de la taille sans perte perceptible.

Comparaison des Formats

WAV (Non compressé)

  • Type : Lossless (non compressé)
  • Débit : 1411 kbps (44.1kHz/16bit/stéréo)
  • Taille (3 min) : ~30 MB
  • Qualité : ★★★★★
  • Compatibilité : Universelle
  • Usage : Production, master

FLAC

  • Type : Lossless (compressé)
  • Compression : ~50-60%
  • Taille (3 min) : ~15 MB
  • Qualité : ★★★★★ (identique à WAV)
  • Compatibilité : Très bonne
  • Usage : Archivage, audiophiles

MP3

  • Type : Lossy
  • Débit typique : 128-320 kbps
  • Taille (3 min, 320kbps) : ~7.2 MB
  • Taille (3 min, 128kbps) : ~2.9 MB
  • Qualité : ★★★☆☆ à ★★★★☆
  • Compatibilité : Universelle
  • Usage : Streaming, partage

AAC

  • Type : Lossy
  • Débit typique : 128-256 kbps
  • Taille (3 min, 256kbps) : ~5.8 MB
  • Qualité : ★★★★☆ (meilleur que MP3)
  • Compatibilité : Excellente
  • Usage : iTunes, YouTube, streaming

Opus

  • Type : Lossy
  • Débit : 6-510 kbps (adaptatif)
  • Taille (3 min, 128kbps) : ~2.9 MB
  • Qualité : ★★★★★ (meilleur que AAC)
  • Compatibilité : Croissante
  • Usage : VoIP, WebRTC, streaming

OGG Vorbis

  • Type : Lossy
  • Débit : 45-500 kbps
  • Taille (3 min, 128kbps) : ~2.9 MB
  • Qualité : ★★★★☆
  • Compatibilité : Bonne
  • Usage : Jeux vidéo, open source
